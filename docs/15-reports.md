# 16. Reports

All reports are filterable by **date range** and **branch** (Owner: single or consolidated; others: their branch only). Every report supports **Excel, CSV, and PDF** export. Heavy reports are generated by background workers and cached.

## 16.1 Report catalog

| Report | Purpose | Key columns / metrics | Visuals | Roles |
|---|---|---|---|---|
| **Revenue** | Income over time | date, branch, package, method, gross, refunds, net | line + stacked bar | Owner, Manager |
| **Expense** | Spend by category | date, branch, category, vendor, amount | pie + bar | Owner, Manager |
| **Profit** | Income − expense | period, income, expense, profit, margin % | line + bar | Owner, Manager |
| **Attendance** | Footfall & peak hours | date, branch, check-ins, unique members, avg duration, peak hour | heatmap + line | Owner, Manager |
| **Trainer** | Trainer performance | trainer, active members, sessions, renewals influenced, adherence | table + bar | Owner, Manager |
| **Member Growth** | Acquisition & churn | new members, renewals, expired, churn %, net growth | line | Owner, Manager |
| **Package** | Sales mix | package, units sold, revenue, avg price, share % | bar + pie | Owner, Manager |
| **Salary** | Payroll spend | staff, type, base, commission, bonus, deduction, net | table | Owner, Manager |
| **Branch Comparison** | Compare branches | branch × {revenue, expense, profit, members, growth, attendance} | grouped bar + table | Owner only |
| **Payment** | Transactions | date, member, method, status, amount, collected_by | table | Owner, Manager |
| **Outstanding / Dues** | Receivables | member, amount, days overdue, aging bucket, last reminder | table + aging bar | Owner, Manager |

## 16.2 Standard filters
- **Period:** Today, This Week, This Month, This Quarter, This Year, Custom range, plus **compare-to-previous-period** toggle.
- **Branch:** single / all (Owner). Managers locked to own.
- **Group by:** day / week / month; by branch / package / method / trainer as relevant.
- **Segment:** active / expired / frozen (where relevant).

## 16.3 Derived metrics & formulas
- **Net revenue** = payments recognized − refunds (period).
- **Profit** = net revenue − expenses (incl. approved salary) (period, branch).
- **Margin %** = profit / net revenue.
- **Churn %** = expired-and-not-renewed / active-at-start.
- **Net growth** = new + reactivated − expired.
- **Renewal rate** = renewals / (memberships expiring in period).
- **ARPU** = net revenue / active members.
- **Avg visit duration** = mean(check_out − check_in).
- **Peak hour** = hour with max check-ins.
- **%Δ** = (current − previous) / previous.

## 16.4 Branch comparison (owner)
- Matrix: rows = branches, columns = chosen metrics; sortable; %Δ vs previous period; best/worst highlighted.
- Charts: grouped bar per metric; trend lines per branch.
- Use cases: which branch leaks profit, which grows fastest, staffing vs footfall.

## 16.5 Export specs
- **Excel:** styled workbook, one sheet per section, totals row, frozen header, number/currency formatting (`exceljs`).
- **CSV:** raw rows, UTF-8, ISO dates, amounts in major units with currency column (documented).
- **PDF:** branded header (business + branch + period), summary KPIs, charts as images, data tables, generated footer (`@react-pdf/renderer`/Puppeteer).
- Exports run as jobs; user notified when ready (download link, short-lived).

## 16.6 Scheduled reports (P3)
- Owner/Manager subscribe to daily/weekly/monthly email digests (revenue, dues, attendance, profit).
- Delivered via email worker; respects timezone.

## 16.7 Data sourcing & performance
- Backed by SQL views / **materialized views** refreshed on schedule for expensive aggregates.
- Read replicas / caching for dashboard KPIs; reconcile with source ledgers.
- All monetary aggregates computed in minor units, formatted at render.
